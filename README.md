# 📌 CUSTOM HOOKS HOMEWORK. Задание №4. `useViewportSize`

## 🚀 О проекте:

- **Стек:** Проект создан с помощью `Create React App`
- **Структура:**
  - Компоненты расположены в папке `components/`
  - Кастомные хуки находятся в папке `hooks/`
  - Вспомогательные функции размещены в `core/helpers/`

## ✅ О выполнении задания:

Для реализации задания был создан хук `useViewportSize`, который:

- Использует `state` для хранения текущих размеров окна
- Добавляет обработчик событий на элемент `window` с помощью вспомогательной функции `useWindowEvent`
- Подписывается на событие `resize` для отслеживания изменений размеров

### 🔄 Возвращаемое значение:
Хук возвращает объект в формате:
```javascript
{ 
  width: window.innerWidth, 
  height: window.innerHeight 
}
